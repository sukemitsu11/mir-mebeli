# Мир мебели — концепт сайта

Адаптивный сайт мебельных салонов «Мир мебели» в Волгограде. Светлый дизайн, каталог направлений, контакты трёх филиалов и подготовка сообщения для WhatsApp.

## Запуск

Нужен Node.js. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Другой порт можно задать переменной окружения `PORT`.

Проверка синтаксиса:

```sh
npm run check
```

## Размещение

Это статический сайт. Для публикации нужны `index.html`, `styles.css`, `app.js` и папка `assets/`. `server.mjs` предназначен для локального предпросмотра. Сервер заявок не подключён: посетитель сам отправляет подготовленное сообщение в WhatsApp.

## Изображения и данные

Первый экран — AI-иллюстрация, отдельные композиции для компьютеров и телефонов. Фотографии мебели взяты из [карточки филиала на Германа Титова, 11 в 2ГИС](https://2gis.ru/volgograd/gallery/firm/4644865397174690). Контакты и категории основаны на предоставленных карточках салонов. Это концепт; фотографии и данные следует согласовать с владельцем перед коммерческой публикацией.

Шрифты Golos Text и Onest хранятся локально. Лицензии SIL OFL находятся в `assets/`.
